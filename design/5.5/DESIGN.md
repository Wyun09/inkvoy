# Inkvoy 5.5 · Ink Instrument（v0.2）

设计契约草案（2026-11-07）。先于 UI 代码存在：颜色、字级、间距、形状、动效、组件全部以本文件为准。UI 与自动生成都读这里，避免再跑偏。

## 定位

**手机上的 AI 工作台，不是聊天应用。**
专业仪器（ProKit）而非消费级（Aqua）：暖纸底 + 墨黑、单一亮绿信号、发丝线分层、等宽字体承担状态与数字。所有"AI 助手"式拟人标签（如助手名字、TRACE、推荐式话术）一律去掉，只保留技术语义：请求、运行、确认、日志。

关键词：精确、克制、可扫读、长时间专注、真实控件、可回放的动效。

## 间距 / 形状 / 层级 / 质感

- 间距 4/8/12/16/20/24/32，8pt 基准；页面左右 17px。
- 圆角 4（chip/小块）/6（按钮、输入、键帽）/8（卡片）/10（弹层）。
- 层级 = 表面阶梯（paper→surface→surface-2）+ 1px 发丝线；卡片无阴影，仅浮层一层柔和阴影。
- **高光（v0.2 重点）**：按钮与键帽顶部 1px 内高光 + 底部 1px 硬阴影；主操作按钮用亮绿竖向渐变（上亮下深）+ 外发光；LED 用 3px 光晕环；卡片四角有 L 形角标（弱）。
- **质感**：全屏纸纹噪点 3–4%；状态行底下一排细刻度尺；终端内 1px 淡网格；分组标题虚线规则；双线边框（外发丝线 + 内高光）。
- 图标 1.45–1.6px 描边、20px 网格、圆角端点，不用填充图标。

## 信息架构（v0.2：取消底部栏）

**导航 = 侧边栏 + 设置模式**，不再有底部 tab 坞。

- **顶部状态行 34px**：菜单按钮 · 品牌标 · 项目/分支 · 页面面包屑（宽屏显示）；右侧 LED · 模型 · tokens · LOCAL 标签。
- **侧边栏（手机抽屉 302px，宽屏常驻）**：项目卡（路径/分支/改动）→ 导航（对话/工作/文件/终端/网页/设置）→ 会话列表（运行/完成 LED + 相对时间）→ 账号与版本。
- **设置模式**：独立整屏，分组行（外观/工作台/连接）+ 分段控件/开关/管理按钮 + 关于卡；从侧边栏或返回键进出。
- **横屏**：左侧 46px 图标轨（侧边栏折叠态）+ 聊天 43% + 9px 分隔条 + 终端 57%。

## 页面规格

**对话**：状态行 → 会话头（标题 / 运行状态 / CTX 条 / 更多）→ 可滚对话 → 命令区。
- 对话为文档：左侧 20px 批注槽（轮次 + 时间），用户消息 = 2px 亮绿竖线 + signal-soft 引言块 + 附件 chip；回复 = 正文文档。
- 元素：详情折叠行（步数/耗时）、PLAN 进度条（2/3 分段）、RUN LOG 台账（工具/参数/状态/耗时，可展开输出）、代码单色 diff、CONFIRM 确认卡（复选 + 主/次按钮）。
- 命令区：队列条（QUEUE/BG/CTX + 草稿压力条）+ 输入行（附件、模式、输入、方形发送键帽）+ 提示行。

**终端（白色/纸面终端）**：亮色下为纸白终端而非黑框；标题栏（DEBIAN/ARM64、UTF-8、尺寸、ZSH）→ 行式输出（左侧时间槽）→ 状态栏（RUNNING/PID + 键帽）；页面顶部为标签页（PTY 01/02）+ 分屏/清屏。暗色主题下终端转为深色对应版本。

**设置模式**：见上；行高 10px 上下，分组虚线，右侧控件统一 22–30px。

## 动效规范

- 屏幕切换：180–200ms，`translateY(7px)+opacity`，`cubic-bezier(.2,.8,.2,1)`。
- 侧边栏：280ms `cubic-bezier(.22,1,.36,1)` 滑入；遮罩 220ms 淡入；关闭更快（160–200ms）。
- 命令区聚焦：边框/阴影 140–180ms；发送按钮按压缩放 0.98（80ms）。
- 台账展开/详情：200–240ms max-height + opacity。
- LED/运行灯：1.4–2.4s 呼吸；光标 1.1s 方波闪烁。
- 尊重 `prefers-reduced-motion` 与设置里的"动效"开关，关闭后全部退化为直接切换。
- 验收：录屏 390×844，逐段检查进入/退出、状态保持与减少动效。

## v0.3 修订（2026-11-07，按用户反馈）

**去掉复古与塑料感，转向干净现代。**
- 色板改为中性白：浅色 #F7F6F3 / #FFFFFF / #F1F0EC，暗色 #0F1114 / #17191D；强调亮绿 #0FAE6E（暗色 #3FE0A0）、亮红 #E23A2C。
- **扁平哑光**：所有按钮/发送键/开关/复选/分段控件去掉渐变、内高光、外发光与内阴影；只用纯色填充 + 1px 发丝线 + 极轻投影（仅浮层）。禁止"塑料"质感。
- 删除复古装饰：纸纹噪点、状态行刻度、卡片角标、终端网格、内嵌高光。
- 顶部删除图标，只用文字 wordmark inkvoy；输入区删除 /、@ 等文字提示行，也删除 QUEUE/DRAFT 注释条。
- 微型大写等宽标签只保留在技术语义处（工具名、终端、状态数字）；其余改为常规中文字体小标签（如"执行记录""计划""待确认""设置模式"）。
- 导航仍为**侧边栏 + 设置模式**，无底部栏；横屏为 46px 图标轨 + 聊天/终端分屏。
- 动效规范不变：页面 190ms、侧边栏 280ms、台账 220ms、色彩 550ms、按压 80ms，支持减少动效。

## v0.4 / v0.5 修订（2026-11-07）：对话框与图标系统

**对话框重构**
- 用户消息改为右侧圆角气泡（浅绿信号底色，最大 82% 宽），附件 chip 右对齐；不再使用整宽引言块。
- 助手回复改为纯文档流：无容器、无边框；推理为无边框"思考 12.4 秒 · 4 步"行；新增极细计划进度条。
- 工具执行改为**可折叠摘要**：默认一行"3 个工具 · 2 完成 · 1 运行"，展开显示行式清单（图标 + 名称 + 参数 + 状态），不再用厚重的台账表格。
- 代码块改为卡片：代码图标 + 文件名 + 增删数 + 复制图标按钮；确认卡改为单选圆点 + 主次按钮。
- 命令区重构为单个圆角输入卡：多行输入 + 底部 icon-only 工具行（附件 / 模式 / 引用）+ 圆形发送按钮，删除独立提示行与 QUEUE 注释条。

**图标系统（全部重做）**
- 自绘统一图标集（24 个 symbol，24px 网格，1.6px 圆头描边，currentColor），通过 SVG sprite <use> 全局复用：菜单、关闭、更多、加号、发送箭头、上下/左右箭头、对话、工作看板、文件、终端、浏览器、设置滑杆、搜索、新会话、账号 chevron、文件、代码、复制、分屏、删除、警告、时钟、链接等。
- **图标按钮一律 icon-only**：发送=箭头、附件=加号、模式=滑杆、引用=链接、更多=圆点、标签页关闭=X、分屏/清屏等；图标内不再出现 ＋、↵、× 等文字字形。
- 侧边栏图标第二代：双气泡（对话）、三列看板（工作）、带内线文件夹（文件）、带标题栏的终端（终端）、带地球的浏览器窗口（网页）、双滑杆（设置）；新增搜索行图标与新会话图标，账号行加 chevron。

**质感与动效**
- 保持扁平哑光；不用渐变/内高光/外发光。抽屉、页面、工具展开、明暗切换的动效参数不变。
