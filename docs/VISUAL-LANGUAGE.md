# Inkvoy conversation UI

当前实现遵循用户提供的 ChatGPT 手机端截图：中性白灰、黑色正文、圆形导航、白色圆角输入区和少量绿色主操作。品牌名称、现有 Logo 与真实功能保持 Inkvoy 自有实现。

## 颜色与层级

浅色底为 `#fafafa`，浮层和输入区为 `#ffffff`，正文为 `#141414`。深色底为 `#141414`，浮层为 `#212121`。默认主操作为 `#00846c`，与白色标签提供可读对比。颜色选择器的标记与实际主题一致，现有强调色偏好继续生效。

正文直接排在页面上，用户消息使用浅色气泡。分隔线与字号承担信息层级，避免反复套入带阴影的大卡片。输入区和操作面板使用 28–30px 圆角；代码、文件和设置使用较小圆角。

## 结构与动效

`js/ui/app-shell/layout.css` 继续独占视口、键盘、安全区和原生浏览器布局。`visual-language.css` 只负责视觉，不对所有应用子节点强制定位。模型、帮助、主题、终端和浏览器入口继续调用原事件处理。

保留已有菜单开合、焦点归还、流式增量、推理展开和 Logo 状态动画。交互可中途反向，减少动态效果时关闭非必要动画；不通过持续移动的大面积背景表现工作状态。

## 检查

`node scripts/audit-layout.mjs after` 使用生产资产生成手机、窄屏、软键盘、横屏、平板、桌面和 30% 缩放预览。菜单、模型入口、文件编辑和终端输入由真实交互测试检查。预览不能替代实体设备体验。
