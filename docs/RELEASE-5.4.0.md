# Inkvoy 5.4.0

版本号 5.4.0 / versionCode 29。本版按照用户提供的 ChatGPT 手机端截图，调整应用的对话、输入区、导航和设置视觉。

- 浅色界面使用中性白灰、黑色正文，默认强调色为青绿；深色界面使用中性炭黑。
- 顶部操作改为圆形按钮组，侧栏、更多操作和设置页面统一圆角、分隔线和留白。
- 底部白色输入区保留模型选择、附件、搜索、命令、引用、工作模式和上下文；支持原有手动收缩与恢复。
- 用户消息使用淡色气泡，AI 正文直接呈现在页面上；思考、执行链和代码保持独立的可展开结构。
- 保留现有 Logo 状态动画、菜单反向过渡、思考展开动画和流式内容过渡，并尊重减少动态效果设置。本版没有重新生成 Logo 或吉祥物素材。
- 文件、模型配置、浏览器和终端采用一致的边界与控件规则。原有模型和工具协议保持不变，包含 5.3.1 的 OpenAI Responses 修复。

## 安装

轻量版不包含 Debian 工具镜像，适合已经初始化环境的设备。离线版包含固定的 ARM64 工具镜像。两种包保留原包名与原签名；安装前请保留重要工作文件。
