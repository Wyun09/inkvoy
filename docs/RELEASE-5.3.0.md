# Inkvoy 5.3.0

这一版重构应用界面层级与交互。保留现有模型连接、终端、浏览器、文件、MCP、插件、计划、目标和团队能力。

## 页面与操作

- 手机聊天页保留会话标题、新建会话和更多操作；输入区域直接靠近屏幕底部。文件、终端、浏览器等工作页面继续显示底部导航。
- 更多操作使用底部操作面板，连接现有的模型设置、搜索、工作区信息、文件、终端、浏览器、主题、外观和帮助入口。支持返回、Escape、焦点约束及关闭时的焦点恢复。
- 刷新等页面操作放到对应标题栏，手机页面去掉重复的大标题。文件页移除撑满屏幕的装饰底板，终端空状态使用直接的启动说明。
- 输入框与命令、引用、工作模式、上下文控制合成一个面板。保留收缩、草稿、附件和快捷命令；收缩后仍可打开计划与目标，AI 提问时让位给问答卡片。
- 重新整理用户消息、回复正文、代码、表格、思考、执行过程和错误输出的间距与层次。完整回复不再常驻额外的完成状态栏。

## 动效与响应

- 操作面板支持打开、关闭及关闭中反向打开。原生网页在弹层出现时暂停显示，关闭后回到原位置。
- 欢迎页使用透明的 Inkvoy 品牌标记，并保留拖动、弹性归位与减少动态效果。回复中的标记仍连续呼吸并根据实际工作阶段过渡。
- 修复长思考展开后的高度上限，并用同一缩放坐标计算反向展开/收起动画的起点。
- 相同任务阶段的连续流式更新不重复改写标题与界面状态；生产 JavaScript 和 CSS 压缩打包。

## 样式边界

核心样式由 `js/ui/app-shell/` 管理。构建阶段通过 PostCSS 从旧业务样式中移除会重新定义标题栏、导航、输入框与回复布局的选择器，再按明确的 CSS 层顺序打包。各工具功能的专用样式保留。

## 安装与验证

版本号 5.3.0 / 27。轻量版与完整版继续使用原包名 `io.github.deepseekbridge` 和原签名，可覆盖安装。工具镜像与 5.2.0 相同，已有环境继续使用。

轻量版仍使用手动导入工具包；本轮没有增加自动下载器。GitHub 发布状态以实际仓库为准，不把本地构建当作已上传。

运行 `npm test` 验证协议与界面，运行 `node scripts/audit-layout.mjs after` 生成视口与页面截图。截图中的任务、工具输出和账号状态为确定性的测试数据。最终结果记录在 `VERIFICATION.md`；框架检查和桌面预览均不代替实体 Android 手机验收。
