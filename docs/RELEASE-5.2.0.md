# Inkvoy 5.2.0

本轮重点是界面布局与安装分发。保留现有模型、计划、目标、团队、终端和浏览器功能。

## 界面与布局

- 同一个视口控制器处理屏幕大小、系统键盘、旋转和 UI 缩放。竖屏键盘缩短页面时保持手机导航。
- 所有弹层使用应用的布局坐标；原生浏览器继续读取最终绘制位置，避免重复计算缩放。
- 30%～110% 档位保留必要的导航与操作尺寸。缩放网格根据按钮真实最小宽度排布，防止相邻按钮覆盖点击区域。
- 对话输入框、回复执行链、设置卡片、模型编辑器统一边框、圆角、间距和明暗表面。窄屏模型配置上下排列，内部滚动，不把整个页面撑宽。
- 长模型名、代码和表格限制在所属区域；分屏根据实际面板宽度调整内容。旋转保留草稿和未保存的 API 输入。
- 保留已有 Logo 连续形态过渡、回复渐显和思考展开动效，以及减少动态效果的设置。

## 两种安装包

| 文件 | 用途 |
| --- | --- |
| `inkvoy-5.2.0-lite.apk` | 约 2.2 MB，不附带 Debian 镜像；聊天和浏览器直接可用。已安装环境可继续使用。 |
| `inkvoy-5.2.0-offline.apk` | 约 616 MB，包含完整 Debian 和工具镜像。首次安装后仍需初始化。 |
| `debian-arm64.tar.gz` | 约 614 MB，轻量版在工具页通过系统文件选择器导入。 |

两种包的包名均为 `io.github.deepseekbridge`，版本号 5.2.0 / 26。同一原始签名可覆盖升级，现有应用数据和工具环境沿用。覆盖升级前无需卸载。

工具包在后台流式写入应用私有目录。文件大小、SHA-256 都必须匹配 APK 内固定清单，成功后才替换缓存。损坏、截断、超大文件或取消会丢弃临时数据，保留旧缓存。初始化环境仍单独检查空间、镜像完整性和提取边界。

当前导入方式为“取得工具包 → 在工具页导入 → 初始化”，尚未实现应用内自动下载。GitHub Releases 还没有上传本次二进制附件。

## 验证方式

`npm test` 覆盖协议与界面交互；Android API 26/33 的 Robolectric 测试覆盖运行时、输入和安装逻辑。`scripts/audit-layout.mjs after` 生成手机、窄屏、键盘、横屏、平板、桌面和最低缩放的截图与边界记录，附带使用示例消息的明暗回复预览。

具体结果见 `VERIFICATION.md`。桌面 Edge 的性能夹具和 Android 框架测试都不能替代实体手机测试；目前没有新增真机验收记录。
